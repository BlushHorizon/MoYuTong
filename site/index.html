常见问题

你可能想问的

需要 API Key 吗？

不需要。默认直接驱动 DeepSeek 网页版（免 Key、免 API 费）。如果你有 OpenAI 兼容的 Key，面板里也能填，走 API 模式。

会不会被 QQ 风控？

高频发消息/发图是风控大头。深瞳内置最小回复间隔、表情包批量单条、40 秒冷却、免打扰时段；但请自行控制频率、遵守平台规则，请勿用于骚扰，建议用小号。

表情包哪来的？

自动收集所有进来的消息：商城表情与图片都入库，并下载本地副本。面板里可以逐条删除或一键清空。

数据在哪？安全吗？

全在本机：D:\深瞳\data（配置、日志、表情包库、浏览器登录态）。没有任何遥测与联网上传。

上下文断了怎么办？

每段对话开头自动发一次完整提示词（含表情包能力段）；答满 50 轮自动开新对话。想立刻重置，点面板上的「② 新建对话」。
