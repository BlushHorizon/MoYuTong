# 深瞳 DeepPupil · QQ 智能体监控台

你 QQ 账号背后的**本地 AI 智能体**：它通过 **OneBot 11 协议**（SnowLuma 提供实现）接入你真实的 QQ 账号，用 **chat.deepseek.com 网页版**当大脑，替你监听消息并自动应答；网页端是一个**深色监控台**（状态卡 / 会话概览 / 实时动态），一切尽在掌握。

---

## 一、它是怎么来的（与 EAgent 的对应关系）

参考的桌面软件 `EAgent.exe` 的工作方式是：启动程序 → 用 Chrome 调试协议（CDP）驱动 `chat.deepseek.com` 页面 → 把消息喂给 DeepSeek → 执行回复/工具，形成一个本地 Agent 循环。

本项目保留同样的产品形态（网页聊天 + 自动应答），但把"被驱动的对象"换成了 QQ：

| EAgent（桌面版） | 本项目（网页版） |
| --- | --- |
| AutoIt 可执行程序 | Node.js 服务 + 浏览器页面 |
| PowerShell 调 CDP 驱动 Chrome | OneBot 11（WebSocket）驱动 QQ |
| 驱动 `chat.deepseek.com` 页面 | 对接真实 QQ 会话（私聊/群聊） |
| DeepSeek 网页对话做 Agent 循环 | OpenAI 兼容接口（DeepSeek 等）做自动回复 |
| 弹窗 GUI | 深色监控台（状态卡 / 会话概览 / 实时动态） |

> **为什么不是直接用 CDP 驱动 QQ 客户端？**
> QQ NT 9.9.x（Electron 37 / Chromium 138）已实测屏蔽 `--remote-debugging-port` 与 `--inspect`，
> 且裁剪了 CDP 的 HTTP 服务端，`application.asar` 又有 RSA-2048 签名校验，无法安全注入。
> 因此改用官方推荐的 OneBot 11 协议接入，稳定性远高于注入/逆向方案。

---

## 二、快速开始

**安装版**（推荐）：双击安装目录里的 `开启.bat`（或桌面快捷方式 **深瞳-开启**），
浏览器会自动打开 `http://127.0.0.1:8787` 的深色监控台；用完双击 **深瞳-关闭**（`关闭.bat`）停止服务。

**源码版**（开发目录）：运行 `start.bat`，效果相同。

> 两个入口共用同一套服务：启动后顶栏显示 QQ 连接状态；
> 首次使用请在 **设置** 里确认 OneBot 地址 / AI 提示词。

## 三、接入真实 QQ（SnowLuma / NapCatQQ 均可，OneBot 11 协议）

本项目只要 **OneBot 11 协议端**，所以 SnowLuma、NapCatQQ、Lagrange 等都能直接用。

### 方案 A：SnowLuma（你本机已在用，推荐）

你机器上已经跑着 `D:\SnowLuma-v1.14.22-win-x64`（账号 你的机器人QQ），
配置文件在 `config\onebot_<QQ号>.json`，其中 `wsServers` 段就是连接信息：

```json
"wsServers": [{
  "name": "ws-default",
  "accessToken": "你的令牌",
  "host": "127.0.0.1",
  "port": 3001,
  "path": "/"
}]
```

只要保证 SnowLuma 在运行，本项目 `config.json` 里配成一样即可（已为你配好）：

```json
"qq": {
  "mode": "onebot",
  "onebot": { "wsUrl": "ws://127.0.0.1:3001", "accessToken": "与 SnowLuma 相同" }
}
```

验证：命令行执行 `node -e "new WebSocket('ws://127.0.0.1:3001/?access_token=xxx')"` 能连上即正常。

> SnowLuma 默认 `reportSelfMessage: false`（不回报自己发的消息），
> 所以网页端做了本地回显；`messageFormat: "array"`（一帧多条）也已适配。

### 方案 B：NapCatQQ

下载 Shell 版：https://github.com/NapNeko/NapCatQQ/releases
1. 扫码登录 QQ
2. WebUI `http://127.0.0.1:6099` → 添加 **OneBot 11 正向 WS 服务器**：`ws://127.0.0.1:3001`，token 留空或与配置一致
3. 本项目设置里模式选 `OneBot 11`、填同样的地址即可

### 切换后

保存配置 → **重启 `start.bat`**（桌面快捷方式重启即可）。
连接成功后，好友和群会自动出现在左侧会话列表，收到的新消息会实时进入网页。

### 4. 配置 AI（可选）

设置 → AI 自动回复，支持三种来源（`AI 引擎`下拉切换）：

| 引擎 | 说明 |
| --- | --- |
| **DeepSeek 网页版**（默认，无需 Key） | 用本机 Edge 打开 `chat.deepseek.com` 并自动驱动：每段新对话先发一次系统提示词，答满 **50 轮**自动开新对话并重发提示词。主界面「DeepSeek 网页版」卡片上有「① 打开浏览器并登录 / ② 新建对话」按钮，点②可手动清空上下文。**Edge 窗口需保持打开**（可最小化）。 |
| **切换网页版模型** | 设置 → 大脑来源选「网页版模型」，在「用哪个网页版模型」里切换 **DeepSeek / 通义千问 / Kimi / 小米 MiMo**——同一套浏览器驱动（CDP）按站点档案跑，各站登录态都存在同一个浏览器配置目录里。新站点首次使用点「① 打开该网站」登录一次（千问=阿里账号、Kimi=月之暗面、MiMo=小米），之后切好点「保存」即可用。切换后提示词与轮次自动重置，新对话照常重发提示词。表情包能力对所有站点通用；**看图回复目前只有 DeepSeek 支持**。 |
| OpenAI 兼容接口 | 填接口地址 / API Key / 模型（`deepseek-chat` 等），纯 API 调用。 |
| 内置规则引擎 | 不联网的兜底应答，方便演示。 |

提示词在设置 → **AI 提示词** 里编辑（`/end` 保存），每次新 DeepSeek 对话自动发送。

**回复对象**（设置 → 回复对象）：
- **全部会话都回复**：好友和群的消息都自动应答（默认）
- **只回复选中的会话**：可多选（按住 Ctrl 点选），选中的会话全部回复，其他任何人/群发来消息都**不回**；一个都不选 = 全部回复，想恢复就切回"全部"
- **群聊主动回复概率**：群里没 @ 机器人的消息按百分比回复（0-100）；@机器人的必回；私聊始终全回。想让机器人"偶尔冒泡"就调低（比如 30）
- **群聊关键词**：填了关键词（逗号分隔）后，群里非 @ 的消息必须命中其中任意一个才回复（@ 和带图消息不受限）；留空 = 不限。
- **免打扰时段**：设一个时间段（如 23:00–08:00，支持跨天），期间不自动回复任何消息；主人发的远程指令不受限。
- **看图回复**：收到图片时自动下载并传给 DeepSeek 看图后再回复（仅网页版大脑支持，设置里可关）。
- **群回@/引用**：群聊自动回复时自动 @ 触发消息的成员并引用其原话（设置里可分别开关；`/api/send` 调试接口支持 `at`/`quoteId` 参数）。
- **QQ 远程指令**：在"指令主人QQ"里填自己的 QQ 号后，直接给机器人发指令即可控制：`/开`、`/暂停 [分钟]`（定时自动恢复）、`/状态`、`/帮助`。
- **自动重启防抽风**：启动器带守护循环，服务进程意外退出 3 秒后自动拉起；DeepSeek 思考卡死超 4 分钟自动复位。
- **真日志**：双击「深瞳-开启」弹出控制台窗口，服务日志（时间戳 + 级别，含每条来信 / 回复 / 跳过原因 / 60 秒心跳）实时滚动；同时**持久写入 `data\app.log`**（追加保存，关窗不丢，超 5MB 自动留档）。**关闭该窗口（或按 Ctrl+C）= 服务随之停止**，`关闭.bat` 停止时窗口也会自己消失。

## 四、目录结构

```
qq-web/
├─ 开启.bat              安装版入口：启动服务并打开网页（纯 ASCII，任意路径可用）
├─ 关闭.bat              停止服务
├─ start.bat             源码版入口（Node 18+，零 npm 依赖）
├─ launcher.ps1          启动守护：日志窗口 / 自动重启 / 停止（bat 与快捷方式都调用它）
├─ config.json           配置（首次运行自动生成）
├─ data/store.json        聊天记录（自动保存）
├─ data/app.log           运行日志（带时间戳，追加保存，关窗不丢）
├─ data/deepseek_profile/ DeepSeek 网页版的 Edge 登录态（保持扫码一次）
├─ server/
│  ├─ server.js           HTTP + SSE + REST + 静态托管
│  ├─ qq-adapter.js       QQ 适配器：OneBot 11 客户端 / 演示适配器
│  ├─ ai.js               AI 自动回复引擎（限流、群聊 @ 规则、上下文）
│  ├─ deepseek-web.js     DeepSeek 网页版驱动（CDP，含 50 轮自动新对话）
│  ├─ stickers.js          表情包（内置）：素材收集 + AI [表情] 标记兑现 + 专属提示词
│  ├─ store.js            会话与消息存储
│  └─ config.js           配置读写
├─ data/stickers.json      表情包素材库（自动收集生成）
└─ public/                网页前端（原生 HTML/CSS/JS，无框架）
   ├─ index.html  style.css  app.js
```

## 五、表情包（内置能力）

机器人**自己会发表情包**——纯文本 AI 做不到的事，靠「专属提示词 + 回复标记协议」实现：

- **素材自动收集**：所有进来的 QQ 消息里，商城表情（mface）与图片都会记进 `data/stickers.json`（同款计数、记时间），库越大发的越多。
- **专属提示词**：`server/stickers.js` 里的【表情包能力】段**自动追加**在网页端填的提示词之后——AI 因此明确知道：自己有这本事、怎么触发、什么时候该用什么时候别用；你改人设不会弄丢这段。
- **标记协议**：AI 想发表情包时在回复里写 `[表情]`（随机来一个）或 `[表情:关键词]`（按素材描述匹配，如 `[表情:笑]`）；服务收到回复后把标记从文字里剥掉，从素材库挑一个跟在文字后面发出去（mface 用 emoji_id 永久有效，图片用 URL 重发）。
- **防刷屏**：一条回复最多兑现一个标记，40 秒冷却（QQ 对高频发图会判骚扰）；冷却中或库里没有就只发文字。图片素材的 QQ 图链过期发不出时会自动剔除该素材。
- **查看库存**：QQ 里发 `/状态`，会显示「表情包素材：N 个」。

> 提示词只在**新对话**开始时发送一次：更新后点主界面「DeepSeek 网页版」卡片的 ② 新建对话，表情包能力即刻生效。

## 七、常见问题

- **网页显示"未连接"**：SnowLuma / OneBot 没起来，或 QQ 当前登录的不是配置里的账号。确认 3001 端口在监听、`config.json` 的 `accessToken` 与 `config\onebot_<QQ号>.json` 一致。
- **AI 不回复**：检查顶栏 AI 开关；引擎是 DeepSeek 网页版时，Edge 窗口要开着且已登录（设置 ① 打开/重启浏览器）；默认私聊和群聊都会自动回复（设置 → 回复范围 / 群聊需@ / 群聊主动回复概率 可调）。
- **DeepSeek 提示词没发**：每段**新对话**开始时只发一次（状态里 `promptSent`）；点主界面「DeepSeek 网页版」卡片的 ② 新建对话或答满 50 轮后会重新发送。
- **启动没反应 / 报错**：看 `data\launcher.log`（启动器）与 `data\app.log`（服务运行日志）；常见原因是 Node.js 未安装（需 18+）或 8787 端口被占用。
- **想回到演示模式**：设置里把模式改回 `演示模式` 并重启。

> 请遵守腾讯官方规则，勿用于骚扰、刷屏或违规用途；高频发送可能触发 QQ 风控。
