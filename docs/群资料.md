## 二、群公告（直接粘贴到 QQ 群公告）

【摸鱼瞳 MoYuTong · 群公告 v1.0.0】

一、这是什么东西
摸鱼瞳是一个本地运行的 QQ AI 智能体：接上你的 QQ（OneBot 11），用 DeepSeek 网页版当大脑，按你设定的规矩自动回消息，并且会自己发表情包。MIT 开源，安装包 2.4 MB。

二、怎么用（3 步）
1）从官网下载安装包，默认装到 D:\摸鱼瞳，覆盖安装不丢数据
2）启动任意 OneBot 11 机器人端（SnowLuma / NapCat），面板填 ws://127.0.0.1:3001
3）双击「开启.bat」→ 面板点「① 打开该网站」扫码登录一次 DeepSeek，之后它自己开工
入群暗号：moyutong520

三、特色功能
· 表情包引擎：自动收藏来信中的表情包/图片并下载本地副本；AI 回复带 [表情] 标记就自动发表情包，多个表情包打包成同一条消息发出，不触发刷屏风控
· 只回该回的人：指定会话可多选，选中的全部回复，其余一律不回；一个都不选=全回
· 群聊规矩：需 @ 才回、关键词过滤、主动回复概率、引用原消息、免打扰时段
· 远程指令：主人在 QQ 里发 /状态 /暂停 /帮助 即可管理

四、常见问题
Q：要 API Key 吗？→ 不要。默认驱动 DeepSeek 网页版，0 花费。
Q：数据安全吗？→ 全在本机 D:\摸鱼瞳\data，无任何遥测与上传。
Q：会被风控吗？→ 高频发消息/发图是风控大头。已内置最小回复间隔、表情包批量单条、40 秒冷却、免打扰时段，但仍请自行控制频率。
Q：支持 Mac/Linux 吗？→ 目前只提供 Windows 安装包。

2）禁止倒卖安装包与源码，禁止冒充官方
3）反馈问题请附 data\app.log 日志，不要只说「坏了」
