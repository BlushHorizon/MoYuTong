FAQ

你可能想问的

需要 API Key 吗？

不需要。默认直接驱动 DeepSeek 网页版（免 Key、免 API 费）。如果你有 OpenAI 兼容的 Key，面板里也能填，走 API 模式。

会不会被 QQ 风控？

高频发消息/发图是风控大头。摸鱼瞳内置最小回复间隔、表情包批量单条、40 秒冷却、免打扰时段；但请自行控制频率、遵守平台规则，请勿用于骚扰，建议用小号。

表情包哪来的？

自动收集所有进来的消息：商城表情与图片都入库，并下载本地副本。面板里可以逐条删除或一键清空。

数据在哪？安全吗？

全在本机：D:\摸鱼瞳\data（配置、日志、表情包库、浏览器登录态）。没有任何遥测与联网上传。

轻量，但有限

整个程序约 144 KB，零 npm 依赖，靠你本机的 Node.js + Edge 跑。只能当玩具玩 / 学习交流，不可用于生产环境，不承诺任何稳定性。

02

无安全措施

它会把 AI 生成的内容自动发到 QQ 群聊，没有审核、没有黑名单、没有人工确认。生成内容可能不当，发出去收不回来。

03

违反 DeepSeek 用户协议

本项目不是反代、没有第三方中转、没有逆向 DeepSeek 网页。原理是用 Node 连接本机浏览器调试端口（CDP）模拟操作，与反代一样均违反 DeepSeek 用户协议，账号可能被临时限制或封禁。

04

QQ 风控

高频发消息/发图是风控大头。内置了最小间隔、批量单条、40 秒冷却、免打扰时段等护栏，但请勿用于骚扰、刷屏、恶作剧，建议用小号。

05

杀软可能误报

NSIS 打包 + 运行时会自动拉起 Edge 并连接调试端口，符合部分杀软对「远控/自动化脚本」的启发式判定，可能误报木马。源码全部公开可自行审计，误报请加白名单。
