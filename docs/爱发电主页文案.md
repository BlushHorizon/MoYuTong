## 3. 创作简介（长版，关于/置顶）

你好，我是 BlushHorizon，一个还在读书的高中生，也是群崽 QunZai 的作者。

群崽 QunZai 是我利用休息日一点点写出来的 QQ 群 AI 搭子：

- 会在群里接梗、斗图、自己发表情包
- 支持 @ 才回、关键词、免打扰、指定会话
- 本地运行，不用 API Key，Windows 双击即用
- MIT 开源，代码全部公开，可以自己审计

它现在还是玩具级作品，离“产品”差得远，但我会继续修 bug、适配新版本、补文档和教程。

**为什么开爱发电？**

软件本身永久免费，没有任何付费功能。开爱发电只是想给持续维护找一个理由：

- 买测试用的小号、服务器和域名
- 补表情包素材、做教程和视频
- 偶尔请自己喝杯咖啡，周末多写两小时代码

**你的支持会变成什么？**

- 更快的 bug 修复和版本更新
- 更完整的安装/配置教程
- 更多表情包和群聊玩法
- 一个继续维护下去的普通高中生

**我的承诺：**

- 免费功能不会锁进付费档
- 不卖账号、不卖数据、不卖 DeepSeek 登录态
- 发电完全自愿，未成年人不要用生活费支持，先问家长
- 软件仍以 MIT 协议开源，你随时可以自己构建

谢谢每一个愿意支持的人。哪怕只是点个 Star、提个建议，也是在帮忙。
