## 一、摸鱼瞳轻量级

整个程序压缩后约 **141 KB**，零 npm 依赖，靠你本机的 Node.js + Edge 跑起来。
它能做的事情很有限：**只能当玩具玩 / 学习交流，不可用于生产环境**，也不承诺任何稳定性、并发或可用性。

## 二、摸鱼瞳无安全措施

- 它会把 **DeepSeek 生成的文本自动发送到 QQ 群聊**。DeepSeek 可能生成不当内容、垃圾信息甚至有害内容，机器人不会替你把关。
- 它**没有内容审核、没有黑名单、没有人工确认**。发了就是发了，删不干净。
- 它能**代表你说话**。用小号之前想清楚。

## 三、DeepSeek 用户协议

**摸鱼瞳不是反代、没有第三方中转、没有逆向 DeepSeek 网页。**

核心原理是：用 PowerShell / Node 连接本机 Chrome/Edge 的调试端口（CDP），通过 WebSocket 在 DeepSeek 页面里执行 JavaScript，模拟输入、上传文件、点击发送，并轮询判断回答是否完成。

**这与反代一样，均违反了 DeepSeek 的用户协议。** 你的账号可能被 DeepSeek 临时限制甚至封禁（例如持续高频自动化访问）。
**作者不承担由此产生的任何责任。**

本项目内置了最小回复间隔、表情包批量单条、40 秒冷却、免打扰时段等护栏，**但仍请自行控制频率、遵守平台规则**。

本项目由 **NSIS 打包**，且运行时会**自动拉起 Edge 浏览器并连接调试端口**——这两点都符合部分杀毒软件对「远控 / 自动化脚本」的启发式判定，因此**存在误报木马的概率**。

> 作者保证：本项目自身**不包含任何恶意代码**。源码全部公开，欢迎自行审计。
