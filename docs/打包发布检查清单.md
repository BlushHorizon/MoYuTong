# 打包发布检查清单

> 每次重新出安装包，按顺序走一遍。**第 1 步不过，就不许打包。**

## 1. 隐私闸门（强制，不可跳过）

```powershell
cd <项目根目录>
node precheck-package.js
if ($LASTEXITCODE -ne 0) { Write-Output "闸门未过，中止"; exit 1 }
```

`dist/` 是安装包的**唯一来源**。闸门会拦截：

| 拦截项 | 例子 |
|---|---|
| OneBot accessToken 明文 | `"accessToken": "Uzg..."` |
| API Key 明文 | `"apiKey": "sk-..."` |
| 真实 QQ 号 | `"commandSenders": "100000000"` |
| 真实会话目标 | `"targetChatKey": "group:123456789"` |
| 11 位 QQ/手机号 | 正文中裸出现的数字串（**邮箱 `xxx@qq.com` 内的放行**） |
| 真实群号 | `group:` + 6 位以上数字 |
| 私人服务器域名 | `*.top` / `*.xyz` / `*.cc` / `*.vip` / `*.cn` |
| 浏览器登录态 | `deepseek_profile/` 目录、`Login Data`、`Cookies` 等文件 |
| 疑似凭据串 | 正文里 >=32 位字母数字混排 |
| `dist/data/` 非空 | 登录态一律由用户自己扫出来，不随包分发 |

> ### 踩过的坑（2026-10-18）
>
> **上一版安装包把开发用的 `config.json` 原样打进去了**，里面带着真实 accessToken、真实 QQ 号、真实群号、私人服务器域名和 5 个成员真名。
>
> 原因：`dist/config.json` 是从开发配置复制来的，而上一轮 P0 修复**只清了 `dist/data/`，漏了根目录的 `config.json`**；
> 而且当时的验证只看 `data/` 目录是否为 0 文件，**没检查根目录的配置文件**，所以漏过去了。
>
> 教训：
> 1. `dist/` 里任何文件都是分发物，包括看起来"只是配置"的那个。
> 2. 验证要**真安装一遍逐文件扫**，不能只看目录清单。
> 3. 闸门要**双向验证**——故意放脏数据进去，确认它真的拦得住（已验证：6 项全部命中）。

## 2. 同步源码到 dist

```powershell
robocopy server dist\server /E /NFL /NDL /NJH /NJS
robocopy public dist\public /E /NFL /NDL /NJH /NJS
```

`dist/config.json` 必须是**干净默认值**（accessToken / commandSenders / targetChatKey 均为空串），
不要用 `qq-web/config.json` 覆盖——那是你自己的运行配置。

## 3. 编译

```powershell
& "C:\Program Files (x86)\NSIS\makensis.exe" setup.nsi
```

- **绝不要用 `File /r "dist\*"`**——带通配符会拍平目录结构
- NSIS 3.13 已移除 `Exclude` 命令，`File /x` 实测无效；排除只能靠显式清单
- `SetCompressor /SOLID lzma` 会把整块压缩，**不能靠扫二进制字符串判断包内容**

## 4. 真实验证（唯一可信的验证方式）

```powershell
# 改注册表指到临时目录
Set-ItemProperty 'HKCU:\Software\MoYuTong' -Name InstallDir -Value 'C:\...\insttest'
Start-Process -FilePath 'H:\安装包\摸鱼瞳MoYuTong安装包.exe' -ArgumentList '/S' -Wait
# 然后逐项检查落盘文件 + 隐私扫描
Start-Process -FilePath 'C:\...\insttest\uninstall.exe' -ArgumentList '/S' -Wait
```

**备份/还原注册表请用 `reg export` / `reg import`（二进制安全）**——
Node 调 PowerShell 传中文路径会编码损坏，把 `D:\摸鱼瞳` 写成 `D:\<U+FFFD><U+FFFD><U+FFFD><U+FFFD>鱼`。

> 卸载会删掉 `HKCU\Software\MoYuTong` 键和 Uninstall 项，**记得一并还原**，
> 否则下次静默安装找不到 InstallDir。

检查项：
- [ ] 文件数符合预期，`data/` 为 0 个文件
- [ ] 隐私扫描 0 命中
- [ ] `public/index.html` 含「关于与声明」区块与 24H 声明
- [ ] HTML 标签完全配对，`modal-body` 在 `modal-foot` 之前已闭合
- [ ] `config.json` 的 accessToken / commandSenders / targetChatKey 均为空

## 5. 分发

同一份 exe 复制到所有分发点，并用 MD5 校验一致：

```
H:\安装包\摸鱼瞳MoYuTong安装包.exe
site\assets\摸鱼瞳MoYuTong安装包.exe
C:\moyutong\05-安装包\摸鱼瞳MoYuTong安装包.exe
```

> GitHub Release 的**附件上传**在部分网络下不可用（`uploads.github.com` 被 DNS 污染），
> 此时 Release 正文改用官网 / raw 直链下载。

## 6. 重装后的收尾

跑一次静默重装（`/S`，InstallDir 指向真实目录）可恢复被卸载测试删掉的：
- 桌面快捷方式（开启 / 关闭）
- 开始菜单快捷方式（开启 / 关闭 / 卸载）
- 控制面板卸载项

重装**不会丢数据**（安装器有"重装保护数据"逻辑，`data/` 1928 个文件验证过完整保留）。
